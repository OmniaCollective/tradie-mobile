# Custom product pages: one per trade (UK)

Each folder has the trade's art, built from the chosen A designs:
- `header-3840x1646.png`: product page header (21:9)
- `search-3840x2560.png` and `search-1920x1280.png`: search results visual (3:2)

Same headline on every page ("Quotes, jobs and invoices. Sorted."), plus "For <trade>." The phone shows that trade's
own jobs on the Home screen (real app captures, UK sample data). The people are generated photos, not real people.
Review canvas: https://claude.ai/artifact/HPumpTPpofeNUcKNhEHJsH ("Trade pages").

Set up in App Store Connect → the app → Custom Product Pages → "+". For each page: name it, upload the art and
screenshots, paste the promotional text, then attach the keywords so the page can show in search for them.
Check the current limits there (number of pages, keywords per page): Apple changes them.
